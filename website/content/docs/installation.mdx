# Installation

codexfi installs through Claude Code's own plugin system. There are no API keys to enter and nothing to configure.

<DocsInstallSteps />

## Prerequisites

- [Claude Code](https://code.claude.com) ≥ 2.1 — the terminal CLI or the VS Code extension
- [Bun](https://bun.sh) or Node ≥ 22.5 on your `PATH`

## Install

In Claude Code, run:

```
/plugin marketplace add prosperitypirate/codexfi
/plugin install codexfi@codexfi
```

Or, from a shell:

```bash
claude plugin marketplace add prosperitypirate/codexfi
claude plugin install codexfi@codexfi
```

Or use the one-liner, which checks for Claude Code and Bun/Node and then runs the same two commands:

```bash
curl -fsSL https://codexfi.com/install | bash
```

Then **start a new Claude Code session**. Memory works automatically from there.

> **VS Code extension only?** The extension doesn't put `claude` on your `PATH`, so the shell commands won't find it. Type the two `/plugin` commands into the Claude Code panel instead — the plugin, settings, and memory are shared between the extension and the terminal.

Claude Code installs the plugin's dependencies itself. The on-device embedding model (~160 MB) is downloaded once, in the background, on first use — your first prompts are never blocked by it.

## What gets installed

| Piece | What it does |
|-------|--------------|
| Hooks | `SessionStart`, `UserPromptSubmit`, `Stop`, `PreCompact`, `SessionEnd` — inject memory and queue extraction |
| MCP server | `memory_search`, `memory_add`, `memory_list`, `memory_forget` tools for Claude |
| Skill | `memory-bank-sync` — folds codexfi's session notes into a `memory-bank/` on "save bank" |
| Data directory | `~/.codexfi/` — SQLite store, job queue, logs, model weights (created on first run) |

codexfi never writes into your repository.

## Verify installation

Check health any time:

```bash
npx codexfi status        # or: bunx codexfi status
```

It checks:

| # | Check | Passes when |
|---|-------|-------------|
| 1 | Claude Code CLI | a `claude` binary is found (PATH, VS Code extension, or known install dirs) |
| 2 | LLM backend | `claude-cli` is available, or an Anthropic API key is set for `anthropic-api` |
| 3 | Embeddings | the local model is ready (or Voyage is configured) |
| 4 | Data directory | `~/.codexfi/` exists and is writable |
| 5 | Config file | `~/.codexfi/codexfi.jsonc` is valid — or absent, which is fine (defaults) |
| 6 | Vector store | the store opens; shows active / total memories |
| 7 | Background worker | worker state and queued jobs |
| 8 | Memory Bank | whether this directory has a `memory-bank/` |
| 9 | Claude Code plugin | `codexfi@codexfi` is enabled in Claude Code |

API keys are reported as set/unset only — never printed. Add `--json` for machine-readable output.

## First session in a project

On the first session in a project with no memories yet, codexfi seeds memory in the background from the project's own files — 28 common files (`README.md`, `package.json`, `Dockerfile`, `tsconfig.json`, monorepo configs, agent instructions like `CLAUDE.md` and `AGENTS.md`, and more) plus the last 20 git commits. From then on, every turn adds to it. Set `"autoInit": false` to turn this off.

## Using a Memory Bank?

If your project has a `memory-bank/` directory, codexfi detects it automatically and stops duplicating it. See the [Claude Code setup guide](/docs/guides/claude-code-setup#memory-bank).

## Updating

Update the plugin through Claude Code's plugin manager (`/plugin`), or from a shell:

```bash
claude plugin marketplace update codexfi
claude plugin update codexfi@codexfi
```

Start a new session afterwards so the new version is loaded.

## Upgrading from 0.7.x (OpenCode)

codexfi 1.0 is Claude Code–only. Your existing `~/.codexfi` store is kept: on first run, the worker re-embeds old Voyage vectors with the local model in the background, and structured memories are usable immediately. Existing project and user scopes are preserved, so nothing is orphaned.

## Uninstalling

```bash
claude plugin uninstall codexfi@codexfi
claude plugin marketplace remove codexfi
rm -rf ~/.codexfi   # optional: deletes all memories and usage data
```
